Kernel Density Workflow & Parameter Sensitivity

Geocoded commercial employment points were weighted by employee count and smoothed with a quartic (biweight) kernel. Search radius was tested across several bandwidths so that hub boundaries reflect genuine agglomeration rather than an artefact of a single smoothing choice.

KDE & Hub Extraction Script
employment_kde.py
Python • ArcPy • Spatial Analyst 
# -------------------------------------------------------------------------
# EMPLOYMENT DENSITY: KERNEL DENSITY ESTIMATION & HUB EXTRACTION
# Input: geocoded business points | Weight: employee count
# -------------------------------------------------------------------------
import arcpy
from arcpy.sa import KernelDensity, Slice

arcpy.CheckOutExtension("Spatial")
arcpy.env.workspace = r"C:\GIS\employment_density.gdb"
arcpy.env.outputCoordinateSystem = arcpy.SpatialReference(2056)  # CH1903+ / LV95

def employment_kde(points, weight_field="EMPLOYEES", cell_size=25, radius=500):
    # 1. Smooth weighted points into a continuous density surface
    kde = KernelDensity(points, weight_field, cell_size, radius, "SQUARE_KILOMETERS")

    # 2. Break the surface into four natural-break tiers
    tiers = Slice(kde, 4, "NATURAL_BREAKS")

    # 3. Vectorise the top tiers into hub polygons
    arcpy.conversion.RasterToPolygon(tiers, "employment_hubs", "SIMPLIFY")
    return kde, tiers

kde_surface, hub_tiers = employment_kde("business_points")
kde_surface.save("employment_kde_500m")
