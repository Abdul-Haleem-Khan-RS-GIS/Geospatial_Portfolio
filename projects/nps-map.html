Hillshade & Shaded Relief Alchemy

Standard single-source hillshading leaves northwestern canyons washed out and southeastern ravines in complete shadow. To honor historical Eduard Imhof Swiss relief techniques, four distinct raster layers were combined inside ArcGIS Pro's raster function chain:

1. MULTI-DIRECTIONAL OBLIQUE ILLUMINATION OPACITY: 65%

Simulates light bouncing from 4 separate angles (225°, 270°, 315°, 360°) to reveal hidden ridges without flattening valley bottoms.

2. TOPOGRAPHIC AMBIENT OCCLUSION BLEND: MULTIPLY 40%

Calculates sky view factor to naturally darken deep glacial cirques, canyons, and couloirs without muddying high-altitude ridges.

3. HYPSOMETRIC TINT OVERLAY BLEND: SOFT LIGHT 75%

Vintage NPS palette: Deep spruce green (#2A442A) grading through tawny ochre (#C5B48B) to pristine glaciated snow fields (#F4F4EE).

# Automated multi-elevation contour extraction and index line tagging
import arcpy
from arcpy.sa import ContourWithBarriers, SurfaceParameters, Raster

# Set Geoprocessing Environment
arcpy.env.workspace = "C:/GIS/CascadePeaks/Project_DB.gdb"
arcpy.env.overwriteOutput = True

dem_raster = Raster("USGS_10M_DEM_CascadePeaks")

# 1. Generate 10-ft Intermediate & 40-ft Index Contours
contour_fc = "Cascade_Contours_Smoothed"
ContourWithBarriers(
    in_surface_raster=dem_raster,
    out_contour_feature_class=contour_fc,
    in_barrier_features="Glacier_Masks",
    contour_interval=10,
    base_contour=0,
    contour_type="CONTOUR"
)

# 2. Tag Index Contours (Modulo 40) & Set Maplex Line Weight Attributes
arcpy.management.AddField(contour_fc, "TYPE", "TEXT", field_length=12)
with arcpy.da.UpdateCursor(contour_fc, ["Contour", "TYPE"]) as cursor:
    for row in cursor:
        row[1] = "INDEX" if (row[0] % 40 == 0) else "INTERMEDIATE"
        cursor.updateRow(row)

# 3. Batch Export 300-DPI A1 Archival Plate
aprx = arcpy.mp.ArcGISProject("C:/GIS/CascadePeaks/CascadeLayout.aprx")
layout = aprx.listLayouts("Cascade_Plate_03")[0]
layout.exportToPDF("Output/Cascade_Peaks_NPS_Plate03_Print300.pdf", resolution=300, image_quality="BEST")
print("[SUCCESS] Topographic Map Series Export Completed.")
