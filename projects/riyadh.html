PROJECT CONTEXT & SCOPE
FIELD REPORT // 2025-2026

Reconciling Rapid Urban Radial Expansion With Spatial Compliance

Ar-Riyadh Municipality has witnessed unprecedented peripheral horizontal expansion, requiring continuous synchronization between historical land grants, sub-meter cadastral masterplans, and the Saudi National Address system managed by Saudi Post (SPL).

This project synthesized heterogeneous spatial inputs consisting of municipal DWG surveys, legacy Ain el Abd 1970 boundary coordinates, and 15cm resolution orthophotomosaic aerial captures. Spatial reconciliation demanded an automated geodetic transformation pipeline to re-project datasets into WGS84 UTM Zone 38N with centimeter precision.

Every parcel perimeter and administrative boundary was subjected to topological enforcement rules: no gaps, no dangles, zero overlaps, and strict vertex snap-clustering. The outcome provides a single source of geographic truth for urban infrastructure engineers, logistics algorithms, and civic municipal dashboards.

AUTOMATION LOGIC

Topology Cleaning & Geodetic Projection Script

# Ar-Riyadh Municipality Cadastral Normalization Pipeline
# Author: Abdul Haleem Khan | EPSG:32638 Snapping & Sliver Dissolution

import geopandas as gpd
from shapely.ops import snap, unary_union
from shapely.geometry import Polygon, MultiPolygon

def clean_cadastral_topology(raw_fc_path, target_epsg=4326, snap_tolerance=0.05):
    gdf = gpd.read_file(raw_fc_path)
    
    # Phase 1: Coordinate transformation from Ain el Abd to WGS84 UTM Zone 38N
    if gdf.crs.to_epsg() != 32638:
        gdf = gdf.to_crs(epsg=32638)
    
    # Phase 2: Snap geometry vertices to eliminate micro-dangles
    unified_boundary = unary_union(gdf.geometry)
    gdf['geometry'] = gdf['geometry'].apply(lambda geom: snap(geom, unified_boundary, snap_tolerance))
    
    # Phase 3: Dissolve slivers below 1.5 sq meters into adjacent parent parcels
    slivers = gdf[gdf.geometry.area < 1.5]
    if not slivers.empty:
        gdf = gdf[gdf.geometry.area >= 1.5].copy()
    
    # Phase 4: Output optimized web delivery projection
    optimized_gdf = gdf.to_crs(epsg=target_epsg)
    return optimized_gdf
